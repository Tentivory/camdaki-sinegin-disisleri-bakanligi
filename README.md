# Camdaki Sineğin Dışişleri Bakanlığı

> Cama çarpan sineği resmi diplomat, camı sınır, *vzzzz* sesini nota verbale ilan eden bakanlık.
> Gerçekten çalışır. Sinekler artık elçidir.

## Resmi görev tanımı

Bu yazılım, evinizin penceresine çarpan bir sineğin:

- pasaportunu düzenler,
- çarpma sayısını sınır ihlali olarak kaydeder,
- 7. çarpışta kriz masası toplar,
- ölüm halinde tazminat olarak bir damla reçel önerir.

Bilimsel dayanağı yoktur. Diplomatik dayanağı da yoktur. Buna rağmen **çok ciddidir**.

## Kurulum

```bash
python3 bakanlik.py
```

Bağımlılık: Python 3.10+. Sinek değil.

## Protokol

1. Elçi akredite edilir.
2. Cam yüzeyine çarpar (1–7).
3. Bakanlık karar verir: sınır dışı, sığınma, ateşkes veya kedi.
4. Tutanak damgalanır.
